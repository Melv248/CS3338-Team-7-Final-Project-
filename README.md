# Objective Breakdown
App to give customers data on foot traffic in an airport so store runners can appropriately handle expected customer volume. Enable restaurant managers to accurately predict customer volume and optimize staffing and inventory based on real-time flight data.

# Software Details
## Goals
Goal of the app is to make it easier for stores to run and manage in airport. Build a website which uses machine learning algorithms to predict customer volume for the next 2-8 hours. The system operates with the airport flight information system to process flight data including schedules and passenger numbers and gate locations and it uses restaurant POS system sales records and flight status updates and gate location information to generate real-time predictions.

## Importance
Our app matters because it allows for effienciency in time and money management. Helps store runners know whether employees can be let go early or whether more items need to be prepped in advance.

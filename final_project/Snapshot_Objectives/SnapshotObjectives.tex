\section{Snapshot 1 -- Project Foundation and Planning}

\subsection{Objective}
The primary goal of Snapshot 1 is to establish the foundation of the Forecast Manager system by creating the project structure, workflow organization, and initial documentation needed for future development.

\subsection{Goals}
\begin{itemize}
\item Create the Jira project board and sprint workflow
\item Establish the GitHub repository structure
\item Draft the Software Design Document (SDD)
\item Draft the Software Requirement Specification (SRS)
\item Create the README and user manual outline
\item Design the initial dashboard wireframes
\item Create the system workflow diagram
\item Define the database structure and project architecture
\item Research machine learning forecasting concepts for customer prediction
\item Create a Docker service outline for deployment planning
\item Identify possible risks, weaknesses, and testing areas
\end{itemize}

\subsection{Reflection}
Snapshot 1 focused primarily on project planning and organizational setup. During this stage, the team created the initial workflow structure, system architecture, and documentation templates required for future development. The project objectives, system goals, and software requirements were clearly defined in preparation for feature expansion in later snapshots.

\section{Snapshot 2 -- Prediction System and Dashboard Features}

\subsection{Objective}
The primary goal of Snapshot 2 is to introduce the customer traffic forecasting system and develop the core dashboard features used by restaurant managers.

\subsection{Goals}
\begin{itemize}
\item Add customer volume prediction functionality
\item Create dashboard visualization prototypes
\item Add staffing recommendation concepts
\item Simulate flight delay and gate assignment integration
\item Add prediction confidence interval displays
\item Create alert notification workflows
\item Generate TestRail testing documentation
\item Update SDD and SRS documentation
\item Expand workflow diagrams and design specifications
\item Add additional dependencies and system configurations
\end{itemize}

\subsection{Reflection}
Snapshot 2 expanded the project by introducing the first major system functionality related to customer traffic forecasting. The dashboard interface and prediction workflows were developed to demonstrate how real-time flight data could support staffing and inventory decisions. Additional testing documentation and updated architectural diagrams were added to support the new functionality.

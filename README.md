# Objective Breakdown
App to give customers data on foot traffic in an airport so store runners can appropriately handle expected customer volume.

# Software Details
## Goals
Goal of the app is to make it easier for stores to run and manage in airport.

## Importance
Our app matters because it allows for effienciency in time and money management. Helps store runners know whether employees can be let go early or whether more items need to be prepped in advance.
